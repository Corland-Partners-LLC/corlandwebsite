# Corland Partners — Design System

Reference for later phases. Source of truth: `tailwind.config.ts`.

## Colors

Primary brand color is **navy**, accent is **teal**. Full shade scales were
generated by tinting/shading the base hex values so components can use
lighter/darker variants (e.g. `bg-navy-50`, `text-navy-700`).

| Token | Hex | Usage |
| --- | --- | --- |
| `navy` / `navy-500` | `#105594` | Primary brand color — headings, buttons, links |
| `navy-50` | `#f3f7fa` | Light tint backgrounds |
| `navy-100` | `#e7eef4` | Card borders, subtle backgrounds |
| `navy-200` | `#c3d5e4` | Borders, dividers |
| `navy-300` | `#9fbbd4` | Muted accents |
| `navy-400` | `#5888b4` | Muted accents |
| `navy-600` | `#0e487e` | Hover state for primary buttons |
| `navy-700` | `#0b3c68` | Link hover, active states |
| `navy-800` | `#092f51` | Dark text on light backgrounds |
| `navy-900` | `#06223b` | Darkest navy — hero backgrounds |
| `teal` / `teal-500` | `#3ec4d1` | Accent color — CTAs, highlights |
| `teal-50`…`teal-900` | generated | Same tint/shade pattern as navy |
| `charcoal` | `#262626` | Footer / dark sections |

Shade scales were produced by mixing the base color toward white (tints,
50–400) and toward black (shades, 600–900), at 50/500/500 being the base
color itself.

## Fonts

Loaded via `next/font/google` in `app/layout.tsx` and exposed as CSS
variables consumed by Tailwind's `fontFamily` config:

- **Heading**: Montserrat, weights 500/600/700/800 — `--font-heading` /
  `font-heading`
- **Body**: Varela Round, weight 400 — `--font-body` / `font-body`

## Layout

- Tailwind's default breakpoints are used (`sm` 640px, `md` 768px, `lg`
  1024px, `xl`/`2xl` 1280px).
- `container` is centered with responsive gutters (`1.5rem` default,
  `2rem` at `lg`) and a max width of `1280px`.

## Components

Shared, reusable building blocks live in `components/`:

- `Header`, `Footer` — site chrome
- `Button` — `variant`: `primary` | `secondary` | `outline` | `ghost`;
  renders as `<a>`/`next/link` when given `href`, otherwise `<button>`
- `Container`, `SectionHeading`, `Breadcrumbs` — layout/typography helpers
- `Hero`, `ImpactCard`, `PillarCard`, `ServiceCard`, `FAQAccordion`,
  `ContactForm`, `CTASection` — content sections (basic styling in this
  phase; later phases may refine visuals without changing props/APIs)

## Content data

All real copy lives in typed modules under `content/` (`company.ts`,
`impact.ts`, `pillars.ts`, `services.ts`, `faq.ts`) — pages import from
there rather than hardcoding copy, so content stays a single source of
truth.
